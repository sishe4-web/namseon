# 17步 Online MVP

브라우저에서 친구와 1:1로 플레이할 수 있는 17보 스타일 웹 게임의 실행 가능한 MVP입니다.

## 실행

Node.js 18 이상 권장.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

친구가 다른 PC에서 접속하려면 서버가 외부에서 접근 가능한 주소로 배포되어 있어야 합니다. 배포 후에는 같은 URL로 접속해 방 코드를 공유하면 됩니다.

## 구현된 기능

- 방 만들기 / 방 참가
- 2인 실시간 WebSocket 플레이
- 선/자 고정 좌석 및 판마다 교대
- 3분 패 구성 타이머
- 각자 34장 중 13장 선택
- 선택한 13장 텐파이/노텐 판정
- 21장 타패 후보 관리
- 선부터 17장씩 번갈아 타패
- 후리텐 / 일시 후리텐
- 리치/일발 상태
- 하저로어는 자의 마지막 타패에만 적용
- 도라/우라도라
- 만관 이상 화료 조건
- 4판 30부 / 3판 60부 절상만관
- 우라도라는 만관 조건 판정 이후 추가
- 만관/하네만/배만/삼배만/역만 계열 정산
- 유국 시 판돈 2배
- 기본적인 리치마작 화료/역/부수 계산 엔진

## 현재 MVP에서 의도적으로 단순화한 부분

이 버전은 실제 배포 가능한 게임 골격과 규칙 엔진을 제공하는 프로토타입입니다. 완전한 일본식 마작 심판 엔진을 목표로 한 상용 규칙 검증기는 아닙니다.

특히 다음은 추가 테스트가 필요합니다.

- 모든 마작 역의 100% 커버리지
- 세부적인 복합 역의 중복 허용/비허용 조합
- 일부 더블역만 조건
- 노텐리치의 원작 세부 처리
- 연결 끊김/재접속 및 방장 권한 관리
- 계정/보안/치팅 방지 강화
- 실제 화폐를 사용하는 결제 기능(현재는 게임 내 판돈 숫자만 사용)

## 프로젝트 구조

```text
17bo-game/
├── server.js
├── package.json
├── README.md
└── public/
    ├── index.html
    ├── styles.css
    └── app.js
```

서버가 `GameState`를 권위적으로 가지고 있으며, 클라이언트에는 상대의 비공개 34장/13장 패가 전달되지 않습니다.
